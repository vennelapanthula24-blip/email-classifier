# 📧 Spam Email Classifier

An AI-powered Spam Email Classifier built using Python and Machine Learning.  
The application uses Natural Language Processing (NLP) to classify messages as **Spam** or **Not Spam**.

## 🚀 Features

- 📩 Classifies messages as Spam or Not Spam
- 🤖 Machine Learning-based prediction
- 📝 TF-IDF text vectorization
- 🌐 Interactive Streamlit web application
- ⚡ Real-time message classification
- 🎯 Approximately 96% test accuracy

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- TF-IDF
- Streamlit
- Machine Learning
- Git & GitHub

## 🧠 How It Works

1. The SMS Spam Collection dataset is loaded.
2. Text messages are converted into numerical features using TF-IDF.
3. A Machine Learning classification model is trained.
4. The trained model predicts whether a new message is Spam or Not Spam.
5. Streamlit provides the interactive web interface.

## 📊 Model Performance

The model achieved approximately **96% accuracy** on the test dataset.
